## 一、基础语法导论

Markdown是一种轻量级标记语言，排版语法简洁，让人们更多地关注内容本身而非排版。它使用易读易写的纯文本格式编写文档，可与HTML混编，可导出 HTML、PDF 以及本身的 .md 格式的文件。因简洁、高效、易读、易写，Markdown被大量使用，如Github、Wikipedia、简书等。

[Markdown 基本语法 | Markdown 教程](https://markdown.com.cn/basic-syntax/)

#### 1. 标题语法

要创建标题，请在单词或短语前面添加井号 `#`。`#` 的数量代表了标题的级别。例如，添加三个 `#` 表示创建一个三级标题 (`<h3>`) (例如：`### My Header`)。

单篇笔记建议只使用一个 `#`，通常用作笔记标题。正文的小标题从 `##` 或 `###` 开始。

不同的 Markdown 应用程序处理 `#` 和标题之间的空格方式并不一致。为了兼容考虑，请用一个空格在 `#` 和标题之间进行分隔。

```
# 一级标题（H1）
## 二级标题（H2）
### 三级标题（H3）
#### 四级标题（H4）
##### 五级标题（H5）
###### 六级标题（H6）
```

#### 2. 强调语法

通过将文本设置为粗体或斜体来强调其重要性。

|     效果     |      语法      |        快捷键         |
| :--------: | :----------: | :----------------: |
|   **加租**   |  `**居中对齐**`  |   `Ctrl/Cmd + B`   |
|    *斜体*    |   `*斜体文字*`   |   `Ctrl/Cmd + I`   |
| ***加粗斜体*** | `***加粗斜体***` | `Ctrl/Cmd + B + I` |
|  ~~删除线~~   | `~~删除线文字~~`  |        `无`         |
|   ==高亮==   |   `==高亮==`   |        `无`         |

#### 3. 引用语法

要创建块引用，请在段落前添加一个 `>` 符号。同时，块引用可以包含多个段落，为段落之间的空白行添加一个 `>` 符号即可。

>Dorothy followed her through many of the beautiful rooms in her castle.
>
>The Witch bade her clean the pots and kettles and sweep the floor and keep the fire fed with wood.

块引用可以嵌套。在要嵌套的段落前添加一个 `>>` 符号。

>Dorothy followed her through many of the beautiful rooms in her castle.
>
>- Revenue was off the chart.
>- Profits were higher than ever.
>
>>The Witch bade her clean the pots and kettles and sweep the floor and keep the fire fed with wood.

#### 4. 列表语法

可以将多个条目组织成有序或无序列表。

无序列表：使用 `-/+/* + 空格`；

有序列表：使用 `数字. + 空格`；

#### 5.代码语法

要将单词或短语表示为代码，请将其包裹在反引号 ( \` ) 中。

要创建代码块，请将其包裹在反引号 ( \`\`\` ) 中。

#### 6.分隔线语法

要创建分隔线，请在单独一行上使用三个或多个星号 (`***`)、破折号 (`---`) 或下划线 (`___`) ，并且不能包含其他内容。

为了兼容性，请在分隔线的前后均添加空白行。

---

#### 7. 链接语法

链接文本放在 [] 内，链接地址放在 () 内，可选择是否添加链接 Title (当鼠标悬停在链接上时会出现的文字)，它放在圆括号中链接地址后面，跟链接地址之间以空格分隔。

```
[超链接显示名](超链接地址 "超链接title")
```

使用尖括号可以很方便地把URL或者email地址变成可点击的链接。

```
<https://markdown.com.cn>
<fake@example.com>
```

强调链接，在链接语法前后增加星号，要将链接表示为代码，请在方括号中添加反引号。

```
I love supporting the **[EFF](https://eff.org)**.
This is the *[Markdown Guide](https://www.markdownguide.org)*.
See the section on [`code`](#code).
```

#### 8.图像语法

要添加图像，请使用感叹号 ( ! )，然后在方括号增加替代文本，图片链接放在圆括号里，括号里的链接后可以增加一个可选的图片标题文本。

```
![这是图片](/assets/img/philly-magic-garden.jpg "Magic Gardens")
```

同时，也可以给给图片增加链接，请将图像的Markdown括在方括号中，然后将链接添加在圆括号中。

```
[![沙漠中的岩石图片](/assets/img/shiprock.jpg "Shiprock")](https://markdown.com.cn)
```

## 二、编写风格

“段间距风格”在Markdown里的执行标准非常明确，核心原则是：**用“一个空行”来标记一个“新段落”或“新块级元素”的开始。** 如果不空行，Markdown解析器会直接“合并”或“错乱”：

- **标题与正文间**：标题写完后，正文开始前，**必须**空一行。否则标题语法可能失效，或者正文被吞并进标题里。
- **段落与段落间**：最核心，只要你想另起一段，**必须**在上一行末尾按两次`Enter`（留下一整行空白）。只按一次`Enter`（换行）在Markdown里被视为“软换行”，渲染出来通常只是一个空格，不会分段。
- **列表与正文间**：写完列表最后一项，如果下一行要切回普通段落，**必须**空一行。如果不空行，下一行文字会被强制续在列表项后面（变成列表的子项）。
- **代码块与上下文间**：代码块的前后**必须**各空一行，否则代码块可能无法正确闭合，甚至把后面的普通文字染成代码颜色。
- **引用块与上下文间**：同理，引用块前后的普通段落必须空一行，否则引用的范围会错乱。
- **表格与上下文间**：表格的上方和下方**必须**空一行，否则表格无法正确渲染。
